# Screenshots

Drop captures in this folder using the exact filenames below. The README and the
User Manual already reference them, so a correctly named file appears
automatically with no edits.

## ⚠️ Redact before committing

Several of these screens show **real citizens' personal data** — full names,
email addresses, home addresses and employment history. A screenshot committed to
git is permanent and survives deletion.

**Before capturing:** sign in as a test account, or blur every name, email and
address. The Applicant Pipeline, Referral Register, Account Matrix and Messages
Hub are the dangerous ones.

## Capture guide

- **Desktop at 1440×900**, browser zoom 100%
- **Light mode** unless demonstrating dark mode specifically
- **PNG**, full window, no browser chrome or personal bookmarks
- Keep each file **under ~500KB** — resize rather than committing multi-megabyte
  captures
- For mobile views, suffix with `-mobile` (e.g. `03-job-board-mobile.png`)

## Placeholders

Until a real capture exists, the reference in the documents simply shows the
filename. That is intentional — a missing screenshot is obvious, whereas a
stale one is misleading.
